About This Project

This blog was built as Task 1 of the Hex Softwares Web Development Internship. The goal was to create a responsive, multi-page blog website using only HTML, CSS, and vanilla JavaScript — no frameworks, no libraries, no build tools.

Four pages, one shared stylesheet, one script file, and localStorage for persistence. That is the entire stack.

The site consists of four pages linked together through a shared navigation bar: a Home page with a hero section and the three most recent posts, a Blog Posts page where you can read all entries and publish new ones, this About page, and a Contact page with a client-side validated form.

Blog posts are stored in the browser using localStorage. That means posts persist across page reloads within the same browser, but they are not shared across devices or sent to any server. If localStorage is empty on first visit, three sample posts are seeded automatically so the page is never blank.

The design follows a teal-and-cream colour palette with the DM Serif Display typeface for headings and Outfit for body text. It is fully responsive, adapting from mobile to desktop with a hamburger menu on smaller screens.

Built by Yongama, a student at the University of Fort Hare, Eastern Cape, South Africa.
